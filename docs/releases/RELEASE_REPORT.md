## Security self-review (not a substitute for independent review)
Findings fixed during build: an unverified-entity event could previously feed a block (now refused); ambiguous CRM timeouts dead-ended (now reconcile); Today hid viewed items (now answer-based). **Open:** no API rate limiting/lockout; erasure doesn't yet propagate to derived text caches (columns exist: `people.erased_at`); dev auth must never be enabled outside development (enforced at config validation in production); CSP/security headers not configured; secrets rely on deployment (file-based env supported); needs independent pen-test.

## Known limitations / honest gaps
Demo evidence pills for claims without a source document show "published unknown" (real extracted claims carry documents). Account coverage records (`account_source_coverage`) have schema + UI but no populator until sources are certified. ATS boards need per-employer slugs (not in the sheets). Apollo/Exa prices unknown, so budgets are zero. Multilingual (PL/DE/Nordic) extraction untested.
